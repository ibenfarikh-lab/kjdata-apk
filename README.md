# KJ Data

Aplikasi Android **KJ Data** — pendamping KJ Data Center untuk membuka, membaca, dan mengelola berkas & dokumen di folder Data Center.

## Unduh versi terbaru

**[Unduh KJ Data (APK)](https://github.com/ibenfarikh-lab/kjdata-apk/releases/latest/download/kjdata.apk)**

Link di atas selalu berisi versi terbaru. Ketuk link-nya, unduh berkas `kjdata.apk`, lalu pasang di HP Android. Tidak perlu login GitHub.

Bila versi baru terbit, link yang sama otomatis berisi APK terbaru — tidak perlu mengganti link yang sudah dibagikan.

## Catatan

- Memasang APK ini tidak otomatis memberi akses ke data. Masuk sebagai member tetap diperiksa dari daftar izin folder Data Center, dan pintu admin tetap hanya untuk pemilik folder.
- Halaman ini hanya berisi berkas unduhan resmi. Kode sumber aplikasi tidak ada di sini.
